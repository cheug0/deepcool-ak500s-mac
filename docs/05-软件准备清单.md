# 05 · 软件准备清单

## A. macOS（黑苹果）侧 —— 开发主环境

| 软件 | 用途 | 获取 |
|---|---|---|
| Xcode Command Line Tools | 编译链（clang、make） | `xcode-select --install` |
| Rust 工具链（rustup + stable） | 主开发语言 | rustup.rs |
| hidapi 系统依赖 | `hidapi` crate 需链接 | `brew install hidapi`（或启用 crate 的 `build-hidapi` 特性源码自编） |
| Homebrew | 上述依赖安装 | brew.sh |
| `hidapitester` | 阶段 0 免编码协议冒烟 | `brew install hidapitester` |
| `osx-cpu-temp` | SMC 温度读法参照/对照读数 | `brew install osx-cpu-temp` |
| Stats（菜单栏监控） | 温度读数交叉校准 | GitHub exelban/stats |
| **OpenCore kexts**：VirtualSMC + SMCProcessor（Intel）/ SMCAMDProcessor（AMD）+ SMCOemSensors | 黑苹果 SMC 温度键的**提供者**，无它则读不到温度 | GitHub 官方仓库（注意与 OC 版本匹配） |
| USBPcap + Wireshark（备一台 Windows 或虚拟机） | B 计划：抓官方软件流量比对 | usbpcap.sourceforge.io |

> 说明：macOS 自带 `hidutil`、`ioreg`，无需另装，用于设备枚举验证。

## E. 硬件与线缆确认

- AK500S 数显版随附的 **USB 2.0 9-pin 转接线**已从散热器底座接出；
- 黑苹果主板有空闲 USB 2.0 9-pin 针脚（若被机箱前面板占用需一分二）；
- BIOS/OC 中该 USB 针脚对应的控制器未被 USB 端口映射（USBMap/USBToolBox）禁用。
