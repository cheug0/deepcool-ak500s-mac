## 风险与对策

| 风险 | 概率 | 影响 | 对策 |
|---|---|---|---|
| 实机为 SE 变体（报文偏移） | 中 | 低 | 协议已含 SE 分支，产品字符串自动识别 |
| 黑苹果缺温度 kext 读不到 CPU 温度 | 中 | 中 | 探测链 + usage-only 降级；README 列出 VirtualSMC/SMCProcessor（AMD 平台 SMCAMDProcessor）安装指引 |
| 固件批次差异导致报文不同 | 低 | 中 | 阶段 0 首先验证；失败即走 USBPcap 抓包 B 计划 |
| macOS 对 HID 无权限拦截 | 低 | 低 | IOKit HID 用户态无需授权；如遇异常用 `doctor` 定位 |
| 唤醒后设备需重新初始化 | 中 | 低 | 电源监听 + 重发加载动画序列 |

## 里程碑验收标准（最终）

1. 黑苹果开机登录后，散热器屏幕在 3 秒内开始显示 CPU 温度；
2. AIDA64/Cinebench 拷机时数值与系统监控工具趋势一致；
3. 温度 ≥ 阈值时报警标志生效；
4. 拔插 USB/睡眠唤醒后 5 秒内自动恢复显示。
